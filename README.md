# Bokang Sibolla

Building AI-native consumer products. Most days that looks like writing a PRD in the morning and reviewing a PR in the afternoon.

Right now I'm building [Sola](https://bokangsibolla.com), an app for women travelling solo (live on iOS). Before this I spent about a decade building digital distribution from close to zero across very different markets and contexts, from MTV Staying Alive to MTN to early-stage product work in South Africa.

### What I'm shipping
- **Sola:** community app for women travelling solo, live on iOS. *React Native, Expo, Supabase*
- **What's On Manila:** curated city guide at [whatsonmnl.com](https://whatsonmnl.com). *Next.js, Supabase*
- **FixMyPrompt:** prompt improver with multi-model compare at [fixmyprompt.tech](https://fixmyprompt.tech)
- **[gtfs-mcp](https://github.com/bokangsibolla/gtfs-mcp):** MCP server that lets AI agents query public-transit schedules from 6,000+ GTFS feeds worldwide. *TypeScript*

I open-source tooling for travel and transit developers here: MCP (Model Context Protocol) servers and TypeScript libraries for moving real travel data into AI agents.

Most of my product code lives in private repos. I work mostly in TypeScript, React Native, Next.js and Supabase, with LLM apps and MCP servers.

I write essays about travel, technology, and how places and platforms actually get built, at [bokangsibolla.com](https://bokangsibolla.com).
